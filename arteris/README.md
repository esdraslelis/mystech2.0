# Arteris

Projeto de apresentação HTML para hospedagem na Hostinger.

O pacote completo foi preparado separadamente em `Arteris_Hostinger_corrigido.zip`, com os arquivos do site diretamente na raiz do ZIP, para envio a `public_html/`.

**Atenção:** os arquivos originais incluem documentos e contratos, que não devem ser publicados automaticamente em repositório público. Por isso, este diretório foi criado como ponto de organização, sem expor esses arquivos.

## Implantação

1. Extraia o ZIP corrigido.
2. Envie seu conteúdo para `public_html/` na Hostinger.
3. Confirme `public_html/index.html` e `public_html/slide1.html`.
4. Abra o endereço do site e clique em **Iniciar apresentação**.

A navegação em tela cheia requer clique do visitante ou F11; não pode ser forçada automaticamente.
