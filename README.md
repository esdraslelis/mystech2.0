# MysTech 2.0

Site institucional imersivo da Mys Tech.

## Stack
- React + Vite
- Three.js
- React Three Fiber
- Drei
- Lenis
- GSAP (próximas cenas)

## Direção
Experiência premium baseada em narrativa por scroll, profundidade 3D, câmera cinematográfica e objetos que atravessam o espaço da interface.

## Rodar
```bash
npm install
npm run dev
```
